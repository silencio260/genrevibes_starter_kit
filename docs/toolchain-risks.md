# Toolchain risk register

This file records build warnings and native requirements that can turn into
future compile failures even when the GenRevibes Dart APIs do not change. Check
it during every Flutter stable upgrade and before widening a vendor constraint.

## Open risks

| Area | Current evidence | Required action | Release effect |
| --- | --- | --- | --- |
| Mixpanel Session Replay on iOS | Flutter 3.44.1 reports that `mixpanel_flutter_session_replay` does not support Swift Package Manager. | Keep this adapter optional and the smoke app on CocoaPods. Track vendor SwiftPM support before enabling Flutter's default integration. | Do not block apps that do not select replay. Block replay-enabled iOS releases if CocoaPods resolution or native compilation fails. |
| Legacy Kotlin plugin application | Flutter 3.44.1 warns about legacy Kotlin Gradle Plugin handling in Firebase Analytics, Firebase Remote Config, Mixpanel, Mixpanel Replay, PostHog, RevenueCat core, and RevenueCat UI plugins. | Re-run the current-stable Android release job on every dependency update. Upgrade or replace the individual adapter before Flutter removes compatibility. | Block only releases selecting a provider that fails the native build. |
| Local notifications on Android | `flutter_local_notifications` 19.x requires core-library desugaring. | Host apps selecting `genrevibes_notifications_local` must enable desugaring and include `desugar_jdk_libs`; the smoke app is the reference configuration. | Android build gate for local-notification users. |
| AdMob across Android Gradle generations | `google_mobile_ads` 6.0.0 fails with the AGP 9 template generated by Flutter 3.44.1, while the adapter API compiled against both its pinned minimum 5.3.1 and current 9.1.0. | Keep minimum-provider contract tests and current-provider native builds. Avoid resolving the incompatible middle version on AGP 9 hosts. | Block AdMob releases unless their resolved version passes the native gate. |
| Apple build-host availability | The local Xcode 26.2 installation exposes the iOS 26.2 SDK but reports its generic iOS destination as ineligible. CocoaPods resolution completes, but a local device release cannot compile until the Xcode platform installation is repaired. | Treat macOS CI as the authoritative iOS release gate and repair/reinstall the local Xcode platform component before calling the local build verified. | The iOS smoke app exists, but this local machine has not completed its Xcode compile gate. |

## Review rules

- Record the exact Flutter, Xcode/AGP, provider, and adapter versions when a new
  warning appears.
- Keep provider workarounds in the provider package or native example; never
  leak their imports or requirements into neutral contracts.
- Remove a risk only after both minimum-provider tests and current-provider
  native release builds pass without its workaround or warning.
- A warning that predicts a future hard failure creates tracked work; it is not
  accepted as permanent background noise.
