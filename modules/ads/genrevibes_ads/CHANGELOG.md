# Changelog

## 0.1.0-dev.3

- Add `AdTestModeProvider`, an optional capability for moving a running install
  between live and test inventory.

## 0.1.0-dev.2

- Add `AdPolicyController.updatePlacements` / `setDefaultPolicy` and
  `AdPlacementPolicy.copyWith` so intervals can be retuned live from remote
  configuration without recreating the controller.

## 0.1.0-dev.1

- Add provider-neutral ad contracts, signals, rewards, and display policy.
