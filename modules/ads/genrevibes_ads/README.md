# genrevibes_ads

Provider-neutral ad placements, formats, rewards, lifecycle events, and display
policy. Logical placement IDs remain stable while each adapter maps them to its
own ad-unit identifiers.

Premium suppression, modal/paywall suppression, first-show delays, repeat
intervals, and the full-screen overlap lock live here rather than inside AdMob,
Appodeal, CAS.AI, or Yodo1 code.
